# Embedded Noto Sans

Regular and bold static TrueType fonts are from the official
[Noto fonts repository](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans).
They are distributed under the SIL Open Font License 1.1 in LICENSE.txt.
The fonts and license are embedded in the API executable; no runtime download is used.
